2. Audit Categories

2.1 Technical SEO

Score: 88/100

What Works

  • HTTPS enforced with Cloudflare Edge CDN and HTTP/3 support
  • robots.txt is valid, accessible (200 OK), and references sitemap.xml
  • XML Sitemap is valid and lists all 81 provincial earthquake routes
  • Canonical link element is properly configured

Findings

HTTP Content-Language header mismatch ('en-US') High

Server sends 'Content-Language: en-US' while the site language is Turkish ('tr_TR'). This may cause geo-targeting confusion for international and regional crawlers.

Recommendation: Configure response header to 'Content-Language: tr' in Spring Boot application settings or reverse proxy.

404 responses return application/problem+json Medium

Non-existent routes return raw Spring Boot JSON error objects rather than a user-friendly HTML error page with navigation links.

Recommendation: Implement an HTML custom 404 error view that guides users back to the map.

2.2 Content Quality & E-E-A-T

Score: 76/100

What Works

  • Official authority citations: Explicitly cites AFAD and Kandilli Rasathanesi
  • Educational FAQ covering magnitude formulas (Mw, ML, Md) and update intervals
  • High information accuracy regarding seismological metrics

Findings

Low static content ratio on raw HTML payload High

The raw HTML contains only ~153 words of static text before JavaScript hydration. Search bots without headless execution may miss dynamic listings.

Recommendation: Server-side render the top 5 most recent significant earthquakes into static HTML.

Missing publisher / organization biographical credentials Medium

Lacks an 'About / Contact / Editorial Policy' section explaining who maintains the platform and disclaimers regarding official emergency response.

Recommendation: Add a transparent About / Methodology modal or footer block with developer/team credentials.

2.3 On-Page SEO

Score: 80/100

What Works

  • Strong title tag (69 characters) containing primary keywords
  • Well-crafted meta description (147 characters) with clear call-to-action
  • Complete Open Graph (og:*) and Twitter Card metadata with high-res image (1200x630)

Findings

Duplicate <h1> tags on homepage Critical

Found two <h1> tags: 'Türkiye Deprem Haritası ve Güncel Depremler | AFAD Verileri' and 'Türkiye Deprem Haritası ve Güncel Depremler'.

Recommendation: Keep exactly one semantic <h1> on the page; demote the second to <h2> or a styled <span>.
